# LayerSwap Stealth

## v1.0.5 (2026-11-21)

- **Remembers your Host setting.** If you log out with Host on, it stays on at your next login. If you log out with Host off, Stealth turns it off again when you log in.
- **Off from the first load.** The first time Stealth loads on a character, it turns Host off right away, even after just a `/reload`, so a fresh install takes effect without a relog.
- The setting is saved separately for each character.

## v1.0.4 (2026-11-21)

- Removed the bypass for LayerSwap's 4-minute Host lock after a swap. LayerSwap 1.14.34 removed the lock itself, so it's no longer needed.

## v1.0.3

- LayerSwap's 4-minute Host lock after a swap is cleared as soon as it starts.

## v1.0.2 (2026-11-12)

- First release on CurseForge.
- Turns LayerSwap's Host off at every login.
